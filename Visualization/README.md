# 🧬 Quantum Molecular Visualization

This folder contains advanced visualizations showing quantum information spreading in molecular systems, demonstrating how small perturbations create chain reactions of quantum correlations.

## 📁 Files

- `create_molecule_viz.py` - Main molecular visualization script
- `run_molecule_viz.bat` - Simple Windows batch file to run visualizations
- `run_molecule_viz_advanced.bat` - Advanced Windows batch file with virtual environment
- `run_molecule_viz.py` - Cross-platform Python script to run visualizations
- `quantum_molecule_visualization.py` - Advanced molecular visualizer with animations
- `README.md` - This file

## 🚀 Quick Start

### Option 1: Windows Batch Files (Recommended for Windows)

#### Simple Version:
```cmd
run_molecule_viz.bat
```

#### Advanced Version (with virtual environment):
```cmd
run_molecule_viz_advanced.bat
```

### Option 2: Python Script (Cross-platform)

```bash
python run_molecule_viz.py
```

### Option 3: Direct Execution

```bash
python create_molecule_viz.py
```

## 🛠️ Troubleshooting

### Common Issues:

1. **Python not found**: Install Python 3.7+ and add to PATH
2. **Package installation fails**: Check internet connection and try upgrading pip
3. **Memory errors**: The visualization can be memory-intensive for complex molecules
4. **Display issues**: Ensure you have a graphics driver that supports 3D rendering

### Getting Help:

- Check the console output for detailed error messages
- Ensure all required packages are installed
- Try running individual functions in the script
- Check available memory (visualization requires ~2GB RAM)
